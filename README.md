# USB-to-UART Converter (CH340G)

A compact USB-to-UART converter designed using the CH340G USB-to-Serial IC. This project was developed in KiCad and provides a reliable interface between a computer and UART-based embedded systems.

## Overview

This converter allows communication between a USB host and microcontrollers through UART serial communication. It is useful for:

- Embedded system debugging
- Firmware flashing
- Serial communication testing
- Raspberry Pi Pico programming
- Arduino and MCU development
- IoT prototyping

---

## Features

✅ CH340G USB-to-UART Bridge IC

## Hardware Specifications

| Operating Voltage | 5V USB Input |
